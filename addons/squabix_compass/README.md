# SQUABIX Compass

A round compass for 3D games. It shows markers for things in the world.

## Classes

- `RadialCompass3D`
- `CompassMarker3D`

## Use

1. Add a `RadialCompass3D` to your UI.
2. Set `center_node` to the node it should follow, like your player.
3. Make a `CompassMarker3D` resource for each thing to show.
4. Change colors, ticks, and directions in the Inspector.

## Demo

See it in the game: https://github.com/squabix/craftlander

## Needs

Godot 4.5 or newer.
